This is a demonstration-ready procedure, not a fabricated user study.

| Task | Expected result | Actual result | Status | Issues |
|---|---|---|---|---|

| Enroll | Student is enrolled in a selected course | To be recorded during demo | Not executed | Requires live participant/test data |
| View resources | Enrolled student can open authorized PDFs | To be recorded during demo | Not executed | Requires live participant/test data |
| Submit assignment | Submission is accepted before the deadline | To be recorded during demo | Not executed | Requires live participant/test data |
| View marks | Student sees published marks | To be recorded during demo | Not executed | Requires live participant/test data |
| Read notification | Student sees relevant notification and can mark it read | To be recorded during demo | Not executed | Requires live participant/test data |
| Search | Search returns only authorized learning material | To be recorded during demo | Not executed | Requires vector/resource data |
